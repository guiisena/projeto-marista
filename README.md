# Cérebro ou Morte!

Jogo de sobrevivência em arena com visão de cima, no tema zumbi. Você é o Tonho, entregador de pizza preso no Cemitério Roxo: ande, atire automaticamente nos zumbis, colete cérebros e escolha melhorias a cada nível.

Tudo em um único arquivo (`index.html`): canvas + JavaScript puro, personagens desenhados em 2D no próprio código e sons gerados com Web Audio.

## Como jogar

- **WASD** ou **setas**: andar
- Tiro automático no zumbi mais próximo
- **1 / 2 / 3**: escolher melhoria ao subir de nível
- **P** ou **Esc**: pausar

Para rodar localmente, é só abrir o `index.html` no navegador.
